>About me:

Hiii! I'm Aditya Goswami, a BSc Computer Science graduate specializing in Artificial Intelligence and Machine Learning from Sharda University. I aim to be a Machine Learning engineer, On the other hand I have co-authored two research papers. I love building stuff and reading philosophy, poetry and documentories.

I built this interactive, voice-driven 3D AI assistant to represent my niche through my portfolio. This portfolio can talk to "Ada", a 3D avatar I named with my nickname in mind i.e. "Adi", Ada answers questions about my background, research and projects in real time.

>What it does?:

~Ask questions by typing or speaking- **Ada** give answers loud and on-screen.
~An interactive rigged 3D avatar reacts differently depending on whether she is idle, listening or speaking.
~This portfolio also have Home/ About/ Projects/ Contact sections

>Architecture:

~**Frontend** : React + Vite
~**3D Avatar**: Maximo avatar with Three.js via react Three Fiber
~**Voice**: Web speech API
~**AI backend**: Groq API
~**Hosting** Vercel
